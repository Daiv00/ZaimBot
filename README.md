# Telegram-бот для Render

Это версия специально для Render.

## Что нужно сделать

1. Создайте репозиторий GitHub и загрузите все файлы из этой папки.
2. В Render нажмите **New → Blueprint** и выберите репозиторий.
3. Render прочитает `render.yaml` и создаст:
   - Web Service
   - PostgreSQL
4. В настройках Web Service заполните:
   - `BOT_TOKEN` — токен BotFather
   - `ADMIN_IDS` — Telegram ID администраторов через запятую
   - `NOTIFY_CHAT_ID` — Telegram ID сотрудника для уведомлений
5. Deploy.

Webhook настраивается автоматически при старте. Никаких `python bot.py`, polling, launcher и ручного запуска на компьютере не требуется.

## Команды

Клиент:
- /start
- 📝 Подать заявку
- 📋 Мои заявки
- /contract_123

Администратор:
- /admin
- /approve_123
- /reject_123
- /paid_123
- /case_123

## Важно про документы

Render Web Service не является постоянным файловым хранилищем. Фото паспортов и PDF здесь временно сохраняются в контейнере. Для реального запуска лучше вынести документы в S3-совместимое защищенное хранилище с ограниченным доступом и сроком удаления.

PostgreSQL хранит данные заявок.

Перед коммерческим использованием проверьте требования к обработке персональных данных и юридическую форму договора.
